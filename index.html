そもそもニューラルネットワークとは？

ニューラルネットワーク（Neural Network）とは、人間の脳にある無数の神経細胞（ニューロン）が信号を伝え合う仕組みを模した数理モデルです。

入力されたデータに対し、各ノード（神経細胞）が「重み（影響力の強さ）」と「バイアス（基準値の調整）」を掛け合わせ、活性化関数（ReLUなど）を通して次の層へバトンを渡します。この層が何重にも連なることで、単純な直線（線形）では表現できない複雑な因果関係やパターンを自動的に捉えることができます。

ノード（単一ニューロン）の数理モデル
① 線形結合（重み付き和とバイアス）: z = w1x1 + w2x2 + ... + wmxm + b = ∑ wjxj + b
② 活性化関数（ReLUによる非線形変換）: a = ReLU(z) = max(0, z) （※ 0以下の信号を遮断し、0超の信号だけを流す）
・x1, ..., xm: 入力特徴量　 ・wj: 各入力の重要度を表す「重み (Weight)」（逆誤差伝播で調整される対象）
・b: 発火しやすさの基準値を底上げ・抑制する「バイアス (Bias)」
多層化による全体の伝播式（本モデル）: h(1) = ReLU(W(1)x + b(1)) ➔ h(2) = ReLU(W(2)h(1) + b(2)) ➔ ŷ = W(3)h(2) + b(3) (線形出力・予測値)
幾何学的視点: ReLUネットワークの正体＝「高次元の超多面体（折り紙）」
※ 本アプリのモデルも全隠れ層で ReLU を採用中

本アプリのニューラルネットワークも、後述の構成図にある通り2つの隠れ層（32ユニット / 16ユニット）すべてに活性化関数として「ReLU」を採用しています。
「複雑な非線形カーブを学習する」と聞くと、ぐにゃぐにゃと曲がった滑らかな曲面を想像しがちですが、数学的には、本モデルを含むReLUネットワークの正体は「超多次元空間において、凄まじい数の平面をつなぎ合わせた多面体（連続区分線形関数: Continuous Piecewise Linear Function）」です。

① 1次元で見れば「無数の関節を持つ折れ線グラフ」
入力が1つの場合、モデルの出力は文字通り無数の折れ曲がり（関節）を持つ折れ線になります。層（深さ）やノード（幅）が増えると、作られる線形領域（直線の区間）の理論上の最大数は指数関数的に爆発します。関節が極小間隔でびっしり並ぶことで、マクロ（人間の目や評価値）にはあたかも綺麗な滑らかな曲線に見えているのです。
② 多次元では「超平面のパッチワーク（折り紙）」
入力が2次元なら「折り目だらけの立体的な多面体サーフェス」、本アプリのような複数次元なら「超空間内で細かく切り分けられた無数の超平面のパッチワーク」となります。曲線を微小な直線メッシュで近似する数値計算と同じ幾何学的構造です。
【実務上の決定的な2大特徴】 ・局所的には常に平らな坂道: 任意の1点に極限までズームすると、そこは常に平らな平面（線形結合）です。そのため勾配が定数となり、勾配消失を起こさずにバックプロパゲーションが安定して深く伝わります。
・領域外の外挿（Extrapolation）は直線: 学習データの範囲から大きく外れた未知の遠くへ行くと、もはや新しい関節は作られず、最後の折れ曲がりの傾きのままただの直線として無限遠まで伸びていく性質があります。これが「ニューラルネットは学習データ範囲外の外挿に弱い」と言われる数学的理由です。
本モデルのレイヤー（層）構成
入力層 (特徴量: Feature_1, Feature_2, Feature_3) ➔ Dense (32ユニット / ReLU) ➔ Dense (16ユニット / ReLU) ➔ 出力層 (Linear / 予測値)

1エポック内で何が行われているのか？（逆誤差伝播法の位置づけ）

「1エポック」とは、用意したすべての訓練データをモデルが1巡学習することを指します。
1エポックの中では、データを小さな塊（バッチサイズ: 例16件）に分け、以下の4つのステップを何十回も繰り返して少しずつ賢くなっていきます。

STEP 1 入力 ➔ 出力
順伝播 (Forward)

入力層から隠れ層を経て出力層へとデータをそのまま流し、現在の重みを使ってモデルが仮の予測値を算出します。

STEP 2 比較
誤差の算出 (Loss)

モデルの予測値と正解データの実測値を突き合わせ、どれだけズレているか（平均二乗誤差: MSE）を算出します。

STEP 3 出力 ➔ 入力
逆誤差伝播法

生じた誤差を出力層から入力層へ向かって逆向きに遡らせ、「どの重みがどれくらい誤差の原因になったか（勾配・偏微分）」を数学的に割り出します。

STEP 4 最適化器
重みの微調整

逆誤差伝播で求めた勾配と学習率（Learning Rate）を基に、オプティマイザ（Adam等）が誤差を減らす方向へ重みをミリ単位で更新します。

※ この4ステップをバッチ単位でぐるぐると回して1エポックが終わると、最後に検証データ（Valデータ）を使って「今の重みで未知のデータに通用するか？」をテストし、グラフに Val Loss としてプロットされます。

逆誤差伝播法の数式メカニズム（連鎖律と数値の具体例）

「出力で生じたズレ（誤差）を、どうやって入力側の各重みに配分するのか？」
その数学的な鍵が高校数学で習う「合成関数の微分（連鎖律: Chain Rule）」です。途中の変数を介して掛け算で勾配（坂の傾き）をバケツリレーのように後ろから前へ伝えます。

基本原理: 誤差の定義式と連鎖律（Chain Rule）による勾配導出
① 誤差（二乗誤差損失: Loss）の定義式: L = ½ ( ŷ - y )2 （※ 微分した際に肩の「2」と打ち消し合って数式を簡潔にするため、慣例的に ½ を掛けます）
② 途中の微分の分解（行間の導出ステップ）:
・誤差 L を予測値 ŷ で微分: ∂L / ∂ŷ = 2 × ½ ( ŷ - y )2 - 1 = ( ŷ - y ) （＝予測と正解の単純な「ズレ幅」）
・予測値 ŷ ( = w · x ) を重み w で微分: ∂ŷ / ∂w = x （＝入力された「データ信号の大きさ」そのもの）
③ 合成関数の微分（連鎖律: Chain Rule）による結合: ∂L / ∂w = ( ∂L / ∂ŷ ) × ( ∂ŷ / ∂w ) = ( ŷ - y ) × x
ごく簡単な数値具体例（入力 x = 2、正解 y = 10 の場合）
※ 線形・活性化関数無しの単純例
※ 理解しやすさを最優先するため、活性化関数（ReLU等の非線形変換）やバイアスを省いた、最も初歩的な1入力・1出力の線形モデル（ŷ = w · x）を想定しています。
現在の重みを w = 3、学習率を η = 0.1 と仮定します。
1. 順伝播（仮の予測）:
ŷ = w × x = 3 × 2 = 6 （正解 10 より 4 足りない）
2. 逆誤差伝播（勾配の計算）:
∂L / ∂w = ( ŷ - y ) × x = ( 6 - 10 ) × 2 = -8 （傾きは「マイナス8」と判明）
3. 重みの更新（Adam等の最適化）:
新w = w - η × (傾き) = 3 - 0.1 × ( -8 ) = 3 + 0.8 = 3.8

➔ 重みが 3 から 3.8 へと自動的に増えました。次の予測値は 3.8 × 2 = 7.6 となり、正解の 10 にグッと近づきます！
※ 実際の多層ネットワークでは、層と層の間に活性化関数（ReLUなど）の傾き（ReLUなら入力が0超で1、0以下で0）が掛け算で挟まりながら、入力層へ向かって順番に連鎖律で遡っていきます。

学習の入れ子構造（エポック・K-Fold・バッチ・重み引き継ぎの仕組み）

学習の処理は、大きな枠組みから微細な更新まで4層の入れ子（マトリョーシカ）構造で行われています。

① 1エポック内でK個のモデルが並行して1巡学習する
「Epoch 1」の間に、Model 1からModel Kまでの全モデルがそれぞれの担当Trainデータで1巡します。本アプリでは全モデルの1巡が終わった時点で進捗バーが1エポック分進み、K個のLossの平均値がグラフに記録されます。
② 各FoldのTrainデータをさらに小さな「バッチ」に分割
例えばTrainが400件、K=5の場合、1つのモデルが学習するデータは320件（残り80件はVal）。
この320件を一度に丸呑みせず、バッチサイズが16なら 320 ÷ 16 = 20個の小包（ミニバッチ） に分割して順番に投入します。
③ 1エポックの中でAdamは何十回も重みを更新している！（直列処理）
各バッチは並列ではなく、バッチ1 ➔ バッチ2 ➔ … と直列（逐次的）に順番に処理されます。
【16件はどう使われる？】 16件のデータをまとめて流し、それぞれのデータから生じた勾配（傾き）の「平均値」を算出します。1件ずつのブレやノイズをならしたこの「平均勾配」を使い、1バッチにつき1回だけAdamが重みを更新します。
そして、直前のバッチで賢くなった最新の重みを受け継いだ状態で次のバッチ（次の16件）が計算されます。つまり1エポック内でAdamは各モデルにつき直列に20回（100エポックなら計2,000回）も重みを微調整し続けています。
④ 次のエポックへ「何」を引き継いで「どう」改善するのか？
引き継がれるのは「直前のエポックの最後（例: 20回目）の更新で得られた最新の重み（Weight）」です。重みはリセットされず蓄積されます。
次のエポックでは、データを再度ランダムにシャッフルした上で、賢くなった重みを初期値として再スタートします。前エポックで取りこぼした誤差をさらに削り落とすように、Adamがより理想的な重みへと収束させていきます。
